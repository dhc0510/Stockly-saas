# ADR-012 · Cierre de STK-005 sin auditoría WCAG completa

Estado: aprobado por el propietario el 2026-11-09. Se aplica a [STK-005](../01-Specs/STK-005/SPEC.md).

- **Verificación:** STK-005 se valida con un recorrido real contra React, Spring Boot y MySQL, más Playwright de las pantallas de acceso a 375 y 1440 px. No se agregan pruebas de integración Java con Testcontainers en este cierre porque requieren Docker.
- **Accesibilidad:** igual que en [ADR-011](ADR-011.md). Teclado, foco, errores con `role="alert"` y estados con `role="status"` se verifican con Playwright. La auditoría WCAG completa queda como mejora general del producto.
- **Demo simulada:** la simulación anterior (`frontend/demo/stk005-server.ts`, su prueba y el script `dev:stk005-demo`) se conserva sin cambios.
- **Correo productivo:** el proveedor SMTP de producción sigue fuera del alcance de STK-005 (SPEC §9). En local se usó un buzón SMTP de prueba.
