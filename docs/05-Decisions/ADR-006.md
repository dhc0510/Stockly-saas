# ADR-006 — Vínculos y reintentos de Ventas STK-011

Aprobado por el propietario el 2026-11-07.

Cobros y Comprobantes vincularán la venta por empresa e identificador interno. El folio se usa para localizar y mostrar la venta. Las reglas de anulación de ventas con pagos o comprobantes se acuerdan al diseñar esos módulos.

Sincronización conserva el UUID del intento y los mismos datos si pierde la respuesta. Un intento registrado devuelve el comprobante original. Un conflicto de precio, existencias o configuración se muestra para revisión según el contrato. Cuando el servidor confirma que el intento no registró la venta y se corrige el borrador, se envía con una clave nueva.
