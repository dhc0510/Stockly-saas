# ADR-007 — Firma, PDF y cifrado para la facturación electrónica STK-013

Aprobado por el propietario el 2026-11-08.

- Stockly se conecta directamente con Hacienda, con las credenciales de cada empresa. No usa un proveedor de facturación externo.
- La firma XAdES-EPES se hace con la librería DSS de la Comisión Europea, usando la llave `.p12` de la empresa. No se implementa una firma propia.
- La representación gráfica en PDF se genera con OpenPDF.
- Las credenciales de Hacienda se cifran con AES-GCM de Java. La clave es la variable de entorno `STOCKLY_BILLING_KEY` (32 bytes en Base64) y no se guarda en la base de datos ni en el código. Si falta, la facturación queda deshabilitada.
- Antes de agregar las dependencias se fijan versiones estables compatibles con Java 21 y Spring Boot 4, y se revisan sus licencias.
